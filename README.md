# compromise-tiles

Pre-cut city data for the sunny-terrace filter of the Compromise iOS app:
building footprints with heights, terrace permits and OpenStreetMap
outdoor-seating venues, and the commune, one JSON file per ~200 m cell in
the app's own cache format (`tiles/<folder>/<int(lat*500)>,<int(lon*500)>.json`).
Generated by `tools/tiles/make_tiles.py` in the Compromise repository, on a
schedule, for the café districts listed in `cities.json`: one entry per
district where the 2026-09-24 re-check found the filter offered (at least
20 terraces in a 400 m cell), each a 1 km square (`half_km: 0.5`).
